## Controls reviewed

Same-origin `/api/v1/` requests alone receive credentials/CSRF; no-store is set and HTTP 401 clears auth state. Cookies/password tokens are not in localStorage (theme preference only). Reset/invitation URL fragments are consumed into memory and removed from history. Context switching requests a backend-validated membership; private resident/report views discard stale in-flight responses/exports. Backend validates every resource identifier and permission, including multi-flat and multi-society cases.

Plain Angular interpolation is used for notice/complaint/resident content. No unsafe HTML bypass/injection APIs, eval or private IndexedDB persistence were found. CSV upload checks file size/type and fatal UTF-8 decoding locally, while backend parsing/limits/tenant approval remain authoritative. Receipt data is fetched through authorized APIs and CSV exports use backend formula-safe bounded content; no user-supplied file path is served.

PWA has one hashed static asset group, no runtime URL patterns and empty data groups. Navigation caches only the static index, never API/financial/resident data. Tests run the actual service worker and inspect cache contents/offline behavior. Lazy feature chunks and build size budgets remain enabled. Labels, associated validation, visible focus, focus trapping/restoration, 320px navigation/tables and light/dark contrast are covered by ESLint and Chromium/Axe regressions; this is not a complete screen-reader audit.
